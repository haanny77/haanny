# 오늘의 날씨

전국 읍·면·동과 해외 도시의 날씨를 확인하고, 어제 날씨와 비교할 수 있는 웹 앱입니다.
설치나 API 키 없이 `index.html`을 브라우저로 열면 바로 실행됩니다. 날씨 조회에는 인터넷 연결이 필요합니다.

## 주요 기능

- **지역 검색:** 도시, 시·군·구, 읍·면·동, 해외 도시 검색 (예: `봉평면`, `평창 봉평면`, `Tokyo`)
- **현재 날씨:** 기온, 체감 온도, 최고·최저 기온
- **어제와 비교:** 시간별 기온 그래프와 기온·강수량·날씨 비교표
- **예보:** 앞으로 24시간과 7일 예보
- **상세 정보:** 미세먼지, 자외선, 습도, 바람, 기압, 강수량, 일출·일몰
- **편의 기능:** 최근 본 지역, 현재 위치 조회, °C/°F 전환

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 검색, 날씨 조회, 화면 표시 |
| `regions.js` | 전국 읍·면·동 이름과 중심 좌표 |

## 참고 사항

- 날씨와 어제 값은 측정소 관측치가 아닌 기상 모델 값이며, 미세먼지도 모델 예측값입니다.
- 리 단위와 일부 법정동은 내장 목록에 없어 Open-Meteo 검색 결과에 의존합니다.
- Open-Meteo 무료 API는 비상업용입니다. 상업적으로 이용하려면 유료 플랜을 확인하세요.

## 데이터 출처

- 날씨·미세먼지·지역 검색: [Open-Meteo](https://open-meteo.com/)
- 읍면동 위치: 본 데이터는 통계청 통계지리정보서비스([SGIS](https://sgis.kostat.go.kr))에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: [vuski/admdongkor](https://github.com/vuski/admdongkor)), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)으로 배포됩니다. 이 앱에서는 2026년 10월판 경계에서 중심 좌표만 계산해 사용합니다.
